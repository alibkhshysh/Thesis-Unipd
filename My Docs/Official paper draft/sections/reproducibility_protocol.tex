\section{Reproducibility Protocol and Data Lineage}
\label{sec:reproducibility}

\subsection{Artifact layout}
\label{sec:repro_layout}

Initial Cohort artifacts are organized under a single workspace root (e.g., \texttt{phase1\_round1/}, equivalent to the \texttt{month2\_round1/} folder in execution notes) with fixed subdirectories:
\texttt{data/}, \texttt{repos/}, \texttt{scripts/}, \texttt{out/}, and \texttt{logs/}. This layout is intentionally stable so that
all extraction and cleaning steps can be rerun without changing paths or script arguments.

\subsection{Execution protocol}
\label{sec:repro_execution}

The pipeline is deterministic given frozen \texttt{versions.csv} and \texttt{windows.csv}. The execution order is:
\begin{enumerate}[leftmargin=*]
  \item \texttt{python scripts/extract\_window\_metrics.py}
  \item \texttt{python scripts/compute\_loc\_per\_tag.py}
  \item \texttt{python scripts/clean\_round1\_metrics.py --windows data/windows.csv}
  \item \texttt{python scripts/recompute\_ownership\_from\_clean.py}\\
  \texttt{--in out/metrics\_window\_dev\_clean.csv --outdir out --windows data/windows.csv}
  \item \texttt{python scripts/compute\_duration\_normalized\_metrics.py}
  \item \texttt{python scripts/compute\_bot\_sensitivity\_outputs.py}
\end{enumerate}

\subsection{Automated validation evidence}
\label{sec:repro_validation}

Validation evidence is recorded in log files and confirms that:
\begin{itemize}[leftmargin=*]
  \item duplicate-key groups merged in cleaning: 0;
  \item windows with zero total churn: 0;
  \item windows with zero total commits: 0;
  \item windows failing share-sum validations (churn or commits): 0;
  \item windows failing unique-author consistency checks: 0;
  \item windows shorter than seven days and flagged as \texttt{sensitivity\_only}: 4;
  \item all-account total mismatches found during bot-sensitivity validation: 0;
  \item bot rows retained for audit: 18; human-only rows exported for primary M3/M4 analysis: 255.
\end{itemize}

These checks establish that downstream Phase II comparative analysis will operate on a coherent and fully auditable dataset.
