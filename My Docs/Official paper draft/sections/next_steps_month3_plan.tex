\section{Planned Next Phase: Comparative Metric Evaluation}
\label{sec:phase2_plan}

Phase II will perform comparative analysis across all candidate metrics using the criteria defined in
Section~\ref{sec:methodology_criteria}, including stability and ranking consistency across consecutive windows.
Only after this comparative evaluation will we apply the smart-contract feasibility rubric and select a single metric
for the baseline PoC implementation.

\subsection{Phase II execution plan}
\label{sec:phase2_execution}

\begin{enumerate}[leftmargin=*]
  \item Compute criterion evidence (C1--C4) for all candidates using the clean, human-only, bot-sensitivity, and duration-normalized Initial Cohort outputs.
  \item Report full-dataset and robust results using the generated short-window sensitivity flags where needed.
  \item Add the Extended Cohort repositories and rerun the full extraction/cleaning pipeline for external-validity support.
  \item Score feasibility dimensions for each candidate using the predefined rubric.
  \item Select exactly one PoC metric using the decision protocol in Section~\ref{sec:decision_protocol}.
  \item Instantiate the selected metric inside the DESTINO-aligned metric-record blueprint in Section~\ref{sec:detailed_design_blueprint}.
\end{enumerate}

\subsection{Decision gate criteria}
\label{sec:phase2_gate}

The PoC metric will be selected only if it simultaneously satisfies:
\begin{itemize}[leftmargin=*]
  \item no feasibility exclusion criterion triggered (Section~\ref{sec:feasibility_rubric_full});
  \item acceptable comparative behavior under C1--C4 relative to alternatives;
  \item reproducible extraction with no unresolved data-integrity issues.
\end{itemize}

This gate prevents premature implementation based on a single attractive but methodologically weak indicator.
