\subsection{Cleaning and validation outcomes}
\label{sec:phase1_execution_validation}

The cleaning and ownership recomputation logs provide concrete numerical guarantees:
\begin{itemize}[leftmargin=*]
  \item input developer-window rows: 273; cleaned rows: 273;
  \item duplicate key groups merged during cleaning: 0 (email-based canonicalization is performed during extraction);
  \item windows with zero churn: 0; windows with zero commits: 0;
  \item bad windows for share-sum checks: 0;
  \item bad windows for unique-author consistency: 0;
  \item duration-normalized rows generated: 28 aggregate-window rows and 273 developer-window rows;
  \item very short windows flagged for sensitivity analysis: 4 windows below seven days;
  \item bot-flagged rows retained in clean data: 18 (click 8, flask 2, requests 3, urllib3 5);
  \item human-only rows generated for primary M3/M4 analysis: 255;
  \item bot contribution: 143 commits (15.85\%) and 939 churn lines (1.61\%).
\end{itemize}

These outcomes confirm that Phase I outputs are analysis-ready and suitable as auditable input for Phase II.
