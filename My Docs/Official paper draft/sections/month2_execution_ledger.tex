\subsection{Cleaning and validation outcomes}
\label{sec:phase1_execution_validation}

The cleaning and recomputation logs provide concrete numerical guarantees:
\begin{itemize}[leftmargin=*]
  \item input developer-window rows: 1118; cleaned rows: 1118;
  \item duplicate key groups merged during cleaning: 0;
  \item windows with zero churn: 0; windows with zero commits: 0;
  \item bad windows for share-sum checks: 0;
  \item bad windows for unique-author consistency: 0;
  \item human-only rows generated for primary M3/M4 analysis: 1063;
  \item bot-flagged rows retained for audit: 55;
  \item bot contribution: 999 commits (10.45\%) and 9294 churn lines (0.45\%);
  \item duration-normalized rows generated: 70 aggregate rows and 1118 developer rows for the all-account layer, plus 70 aggregate rows and 1063 developer rows for the human-only layer;
  \item windows shorter than seven days and flagged as \texttt{sensitivity\_only}: 22.
\end{itemize}

These outcomes confirm that the centralized Phase I artifacts are internally consistent and ready
to serve as auditable input for Phase II.
