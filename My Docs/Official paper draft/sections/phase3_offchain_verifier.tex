\section{Phase III: Off-chain Verifier and Evidence Replay}
\label{sec:phase3_offchain_verifier}

The first implemented PoC boundary is the off-chain evidence path. It does not read a selected row from the frozen
ownership CSV. Instead, it resolves the pinned Git tags, checks commit ancestry, traverses the release range, applies the
frozen identity and bot policies, recomputes M4 using integer arithmetic, creates the evidence commitments, and emits the
ledger submission defined by the frozen schema.

\subsection{Standalone Git evidence artifact}
\label{sec:phase3_git_bundle}

The evidence builder creates a Git bundle version 2 containing both annotated tag refs, \texttt{2.4.0} and
\texttt{2.5.0}. No prerequisite object is declared, so the artifact can populate a fresh repository without access to the
original working copy. To test build determinism, the builder creates two bundles with single-thread packing and rejects the
result unless their raw-byte SHA-256 values are identical.

The resulting artifact is 7,206,262 bytes. Its SHA-256 is:

\subsection{Fresh-bundle replay and independent traversal}
\label{sec:phase3_offchain_replay}

The replay check initializes an empty bare repository and fetches only the two tag refs from the bundle. Running the primary
verifier in that repository reproduces four files byte-for-byte: the manifest, ledger submission, developer audit, and
verification summary. Their hashes are unchanged across repeated complete pipeline runs.

A second extraction route checks for a shared-parser error. It enumerates the 16 non-merge commits with \texttt{git rev-list},
reads author metadata per commit, and accumulates each commit's changes with \texttt{git diff-tree --numstat}. This route does
not use the verifier's \texttt{git log --numstat} parser. It independently matches every commit, developer, bot, added,
deleted, churn, binary, numerator, denominator, and ppm field committed in the manifest.

Thirteen automated tests pass. They cover the exhaustive ppm test from Section~\ref{sec:phase3_metric_freeze}, canonical
serialization, identity normalization, bot and binary handling, generated-schema validation, the artifact--manifest--submission
hash chain, and zero-failure summaries. Negative tests reject both an additional submission field and a one-ppm arithmetic
mutation. Repeated execution checks nine generated files and logs with zero hash differences.

\subsection{Interpretation and off-chain boundary}
\label{sec:phase3_offchain_boundary_result}

This step establishes deterministic extraction, calculation, serialization, commitment, and local replay for one ancestral
fixture. It does not prove control of an author email, perfect bot identification, semantic value of churn, permanent bundle
availability, or generalization beyond the evaluated windows. Section~\ref{sec:phase3_chaincode_unit} tests authorization,
duplicate prevention, state, history, queries, and events at the contract-unit boundary; Section~\ref{sec:phase3_fabric_network}
then evaluates endorsement, ordering, commit observation, authenticated rejection, and Gateway delivery. The bundle necessarily retains the repository's original author
metadata; the pseudonymous developer hash limits the compact ledger subject field but does not anonymize the off-chain evidence
artifact.
