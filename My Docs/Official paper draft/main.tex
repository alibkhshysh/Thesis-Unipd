\begin{abstract}
This report consolidates Phase I of the thesis: the construction of a centralized,
reproducible dataset and extraction pipeline for developer-reputation candidate metrics.
The final Phase I dataset contains ten open-source repositories, each frozen at eight
stable release tags and seven consecutive release windows. The report documents repository
and version-window curation, metric extraction for M1--M4, cleaning and validation,
bot-sensitivity handling, and duration-normalized outputs for uneven release windows.
The comparative evaluation phase (Phase II) is intentionally deferred. No proof-of-concept
(PoC) metric is selected in this report; that decision is made only after comparative
analysis and feasibility scoring.
\end{abstract}
