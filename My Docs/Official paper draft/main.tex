\begin{abstract}
This report consolidates thesis work completed in Phase I (Initial Cohort), focused on
building and validating the extraction pipeline for developer-reputation candidate metrics
under defined evidence and reproducibility constraints. The document reports repository and version-window curation,
pipeline outputs, and post-extraction data cleaning outcomes. The comparative evaluation
phase (Phase II) is intentionally deferred, and no proof-of-concept (PoC) metric is selected
at this stage. PoC metric selection is explicitly performed after Phase II comparative
evaluation using the feasibility rubric.
\end{abstract}
